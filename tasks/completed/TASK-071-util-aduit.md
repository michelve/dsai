## Missing primitives and redundancy hotspots

- Commented exports in `utils/index.ts` call out absent primitives (debounce/throttle, date/number formatting, string helpers, deepMerge/pick/omit) that exist in MUI (`debounce`, `ownerDocument`, `capitalize`) and Ant (`throttleByAnimationFrame`, `raf`, `responsiveObserve`).【F:packages/@dsai/react/src/utils/index.ts†L120-L125】 Filling these would reduce app-level reimplementations.
- Focus management lacks portal-aware focus restoration, scroll lock, inert/aria-hidden management, and utility for returning focus to the trigger, all present in MUI TrapFocus and Ant FocusLock wrappers.【F:packages/@dsai/react/src/utils/a11y/trapFocus.ts†L27-L70】
- Event normalization primitives are absent: no pointer/keyboard normalization, no `composeEventHandlers`, and no `extractEventHandlers` equivalent, leaving components to duplicate boilerplate.
- CSS/DOM measurement helpers (bounding rect, resize observers, `ownerDocument/Window`, scroll position) are missing, unlike MUI/Ant layout hooks.
- Token/variant helpers are string-based only; there is no hook into the design tokens package for variants, CSS variables, or typography scale mappings.【F:packages/@dsai/react/src/utils/string/getVariantClass.ts†L13-L63】
- Redundant definitions across modules (generateId, isBrowser, prefersReducedMotion, clamp, mergeRefs, href validators) increase maintenance and type drift.【F:packages/@dsai/react/src/utils/index.ts†L26-L118】【F:packages/@dsai/react/src/utils/a11y/generateId.ts†L1-L15】【F:packages/@dsai/react/src/utils/browser/isBrowser.ts†L1-L6】【F:packages/@dsai/react/src/utils/browser/prefersReducedMotion.ts†L1-L11】【F:packages/@dsai/react/src/utils/number/clamp.ts†L1-L10】【F:packages/@dsai/react/src/utils/validation/isSafeHref.ts†L1-L83】【F:packages/@dsai/react/src/utils/validation/isValidHref.ts†L1-L69】

## Error handling, edge cases, and defaults vs MUI/Ant

- Several helpers swallow errors (e.g., `mergeRefs` ignores ref assignment failures) instead of surfacing warnings like Ant’s `_util/warning` or throwing in dev, which can mask ref churn bugs.【F:packages/@dsai/react/src/utils/dom/mergeRefs.ts†L12-L25】
- SSR defaults are inconsistent: root `isBrowser` ignores `document`, while browser version checks both; `generateId` randomizes per render, risking hydration mismatches compared to MUI’s deterministic `useId`.【F:packages/@dsai/react/src/utils/index.ts†L26-L78】【F:packages/@dsai/react/src/utils/browser/isBrowser.ts†L1-L6】
- Accessibility coverage is partial: `trapFocus` does not restore focus to the opener, prevent page scroll, or handle dynamically added focusables, unlike MUI/Ant defaults. Keyboard helpers lack `event.preventDefault` guidance for form submits or IME composition.【F:packages/@dsai/react/src/utils/a11y/trapFocus.ts†L27-L70】【F:packages/@dsai/react/src/utils/keyboard/isEnterKey.ts†L1-L8】【F:packages/@dsai/react/src/utils/keyboard/isEscapeKey.ts†L1-L7】
- Default config coverage is thin: `normalizeTriggers` accepts any string and does not apply library defaults (e.g., Ant’s hover+focus for Tooltip), and `mapPlacement` lacks RTL/flip logic that MUI/Ant provide.【F:packages/@dsai/react/src/utils/misc/mapPlacement.ts†L17-L45】【F:packages/@dsai/react/src/utils/misc/normalizeTriggers.ts†L14-L33】
