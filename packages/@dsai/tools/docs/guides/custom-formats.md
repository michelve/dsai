# Custom Formats

Learn how to create custom output formats for specialized platform needs.

## Overview

Formats define how tokens are output to files. Custom formats allow you to:

- Generate code for any language or framework
- Create specialized documentation
- Output tokens for proprietary systems
- Build custom asset pipelines

---

## Creating a Format

### Basic Format

```typescript
import { defineConfig } from '@dsai/tools';

export default defineConfig({
  formats: {
    customFormats: [
      {
        name: 'custom/scss-map',
        formatter: ({ tokens, platform }) => {
          const lines = tokens.map((token) => `  "${token.name}": ${token.value},`);
          return `$${platform.name}-tokens: (\n${lines.join('\n')}\n);`;
        },
      },
    ],
  },
});
```

### Format Interface

```typescript
interface Format {
  name: string;
  formatter: (options: FormatOptions) => string;
}

interface FormatOptions {
  tokens: TransformedToken[];
  platform: Platform;
  config: ResolvedConfig;
  file: FileConfig;
  options?: Record<string, unknown>;
}
```

## Format Examples

### TypeScript Declarations

```typescript
{
  name: 'ts/declarations',
  formatter: ({ tokens }) => {
    const lines = tokens.map((token) => {
      const type = getTypeScriptType(token.type);
      return `  readonly ${token.name}: ${type};`;
    });

    return `export interface DesignTokens {\n${lines.join('\n')}\n}\n`;
  },
}
```

### JSON with Metadata

```typescript
{
  name: 'json/withMetadata',
  formatter: ({ tokens, config }) => {
    const output = {
      $schema: 'https://example.com/tokens.schema.json',
      $version: config.version,
      $generated: new Date().toISOString(),
      tokens: tokens.reduce((acc, token) => {
        acc[token.name] = {
          value: token.value,
          type: token.type,
          description: token.description,
        };
        return acc;
      }, {}),
    };

    return JSON.stringify(output, null, 2);
  },
}
```

### React Theme Provider

```typescript
{
  name: 'react/theme',
  formatter: ({ tokens }) => {
    const theme = buildNestedObject(tokens);

    return `
import { createContext, useContext } from 'react';

export const theme = ${JSON.stringify(theme, null, 2)} as const;

export type Theme = typeof theme;

const ThemeContext = createContext<Theme>(theme);

export const useTheme = () => useContext(ThemeContext);
export const ThemeProvider = ThemeContext.Provider;
`.trim();
  },
}
```

## Format Options

Pass custom options to formats:

```typescript
export default defineConfig({
  platforms: {
    web: {
      files: [
        {
          destination: 'tokens.css',
          format: 'css/variables',
          options: {
            selector: ':root',
            outputReferences: true,
          },
        },
        {
          destination: 'tokens-dark.css',
          format: 'css/variables',
          options: {
            selector: '[data-theme="dark"]',
            outputReferences: true,
          },
        },
      ],
    },
  },
});
```

Access options in your format:

```typescript
{
  name: 'css/variables',
  formatter: ({ tokens, options }) => {
    const selector = options?.selector || ':root';
    const lines = tokens.map((token) => `  --${token.name}: ${token.value};`);

    return `${selector} {\n${lines.join('\n')}\n}`;
  },
}
```

## Header and Footer

Add headers to generated files:

```typescript
{
  name: 'custom/withHeader',
  formatter: ({ tokens, config, file }) => {
    const header = `/**
 * @generated by @dsai/tools v${config.version}
 * Do not edit directly
 * Generated: ${new Date().toISOString()}
 */\n\n`;

    const content = tokens.map((t) => `--${t.name}: ${t.value};`).join('\n');

    return header + content;
  },
}
```

## Token Filtering

Filter tokens in your format:

```typescript
{
  name: 'css/colors-only',
  formatter: ({ tokens }) => {
    const colorTokens = tokens.filter((t) => t.type === 'color');

    const lines = colorTokens.map(
      (token) => `  --${token.name}: ${token.value};`
    );

    return `:root {\n${lines.join('\n')}\n}`;
  },
}
```

## Multi-File Formats

Generate multiple files from one format:

```typescript
{
  name: 'components/split',
  formatter: ({ tokens }) => {
    // Group tokens by component
    const grouped = groupBy(tokens, (t) => t.attributes?.component);

    // Return object for multi-file output
    return Object.entries(grouped).reduce((acc, [component, componentTokens]) => {
      acc[`${component}.css`] = formatCssVariables(componentTokens);
      return acc;
    }, {});
  },
}
```

## Reference Resolution

Handle token references in output:

```typescript
{
  name: 'css/withReferences',
  formatter: ({ tokens, options }) => {
    const lines = tokens.map((token) => {
      let value = token.value;

      // Keep references in output
      if (options?.outputReferences && token.original?.value?.startsWith('{')) {
        const refName = token.original.value.replace(/[{}]/g, '').replace(/\./g, '-');
        value = `var(--${refName})`;
      }

      return `  --${token.name}: ${value};`;
    });

    return `:root {\n${lines.join('\n')}\n}`;
  },
}
```

## Testing Formats

```typescript
import { createFormatContext, runFormat } from '@dsai/tools/testing';

describe('custom/scss-map format', () => {
  it('generates valid SCSS map', () => {
    const context = createFormatContext();
    const tokens = [
      { name: 'color-primary', value: '#007bff', type: 'color' },
      { name: 'color-secondary', value: '#6c757d', type: 'color' },
    ];

    const result = runFormat('custom/scss-map', tokens, context);

    expect(result).toContain('$web-tokens');
    expect(result).toContain('"color-primary": #007bff');
  });
});
```

## Best Practices

1. **Valid Output** - Ensure generated code is syntactically valid
2. **Formatting** - Use consistent indentation and style
3. **Comments** - Include generation metadata in headers
4. **References** - Support token references when appropriate
5. **Error Handling** - Handle edge cases gracefully
