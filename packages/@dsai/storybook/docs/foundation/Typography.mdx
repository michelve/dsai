## Overview

Our typography system includes:

- **Display Typography** (Display 1-6): Large, attention-grabbing text for hero sections
- **Headings** (H1-H6): Semantic heading hierarchy for content structure
- **Font Families**: System font stacks for base and monospace
- **Font Sizes**: Modular scale from 12px to 80px
- **Font Weights**: From light (300) to bolder (900)
- **Line Heights**: Contextual line heights for optimal readability
- **Letter Spacing**: Fine-tuning for different text sizes and purposes

## Display Typography

Display typography is designed for hero sections, landing pages, and marketing content. It features:

- **Larger sizes**: 40px to 80px (2.5rem to 5rem)
- **Lighter weight**: 300 (light) for elegant, modern appearance
- **Tighter line-height**: 1.2 for visual impact
- **Negative letter-spacing**: -0.02em for better balance at large sizes

### Best Practices

**DO:**

- Use proper semantic HTML (`<h1>`, `<h2>`, etc.)
- Maintain heading hierarchy (don't skip levels)
- One `<h1>` per page for SEO and accessibility
- Use headings for structure, not just styling

**DON'T:**

- Don't use display typography for semantic headings

## Font Families

### Base Font Family

```css
font-family: var(--dsai-typography-font-family-base);
/* System font stack: system-ui, -apple-system, "Segoe UI", Roboto, etc. */
```

**Benefits:**

- Native OS fonts for optimal performance
- No font downloads required
- Familiar to users on each platform
- Excellent readability across all devices

### Monospace Font Family

```css
font-family: var(--dsai-typography-font-family-monospace);
/* Monospace stack: SFMono-Regular, Menlo, Monaco, Consolas, etc. */
```

**Use for:**

- Code snippets and examples
- Technical documentation
- Terminal/console output
- Data tables with aligned columns

| -------- | --------------- | ---------------------- |
| **xs**   | 12px (0.75rem)  | Fine print, captions   |
| **sm**   | 14px (0.875rem) | Secondary text, labels |
| **base** | 16px (1rem)     | Body text (default)    |
| **lg**   | 18px (1.125rem) | Emphasized body text   |
| **xl**   | 20px (1.25rem)  | Lead paragraphs        |
| **2xl**  | 24px (1.5rem)   | Large text             |
| **3xl**  | 30px (1.875rem) | Extra large text       |

## Font Weight Scale

| Token        | Value | Usage                         |
| ------------ | ----- | ----------------------------- |
| **lighter**  | 100   | Rarely used                   |
| **light**    | 300   | Display typography, lead text |
| **normal**   | 400   | Body text (default)           |
| **medium**   | 500   | Headings, emphasized text     |
| **semibold** | 600   | Strong emphasis, subheadings  |
| **bold**     | 700   | Bold text, CTAs               |
| **bolder**   | 900   | Maximum emphasis              |

## Line Height Scale

| Token             | Ratio | Usage                         |
| ----------------- | ----- | ----------------------------- |
| **xs**            | 1.0   | Compact UI, tags, badges      |
| **sm / tight**    | 1.25  | Headings, display text        |
| **base / normal** | 1.5   | Body text (WCAG AA compliant) |
| **relaxed**       | 1.75  | Long-form content, articles   |
| **lg / loose**    | 2.0   | Spacious layouts              |
| **display-sm**    | 1.2   | Small display text (40px)     |
| **display-md**    | 1.2   | Medium display text (48-56px) |
| **display-lg**    | 1.2   | Large display text (64px+)    |

### Accessibility Note

WCAG 2.1 requires a minimum line-height of **1.5** for body text. Our `base` token meets this requirement.

## Letter Spacing

| ----------- | -------- | ----------------------------- |
| **tighter** | -0.05em  | Large headings, display text  |
| **tight**   | -0.025em | Headings                      |
| **normal**  | 0        | Body text (default)           |
| **wide**    | 0.025em  | Small text, uppercase         |
| **wider**   | 0.05em   | All-caps, labels, buttons     |
| **widest**  | 0.1em    | Decorative, all-caps headings |

## Responsive Typography

### Mobile-First Approach

```css
/* Mobile (default) */
.hero-title {
  font-size: var(--dsai-typography-display-display5-font-size); /* 48px */
}

/* Tablet */
@media (min-width: 768px) {
  .hero-title {
    font-size: var(--dsai-typography-display-display3-font-size); /* 64px */
  }
}

/* Desktop */
@media (min-width: 1200px) {
  .hero-title {
    font-size: var(--dsai-typography-display-display1-font-size); /* 80px */
  }
}
```

### Fluid Typography

```css
.hero-title {
  /* Scales between 48px and 80px based on viewport width */
  font-size: clamp(48px, 5vw + 1rem, 80px);
}
```

## Accessibility Guidelines

### Contrast Requirements (WCAG 2.1 AA)

| Text Size                        | Minimum Contrast | Example                  |
| -------------------------------- | ---------------- | ------------------------ |
| Normal text (< 18px)             | 4.5:1            | Body text on backgrounds |
| Large text (≥ 18px or 14px bold) | 3:1              | Headings, display text   |
| UI components                    | 3:1              | Buttons, form controls   |

### Best Practices

**DO:**

- Use minimum 16px for body text
- Maintain 1.5 line-height for body text
- Keep lines between 45-75 characters for readability
- Use relative units (rem, em) for scalability
- Test with browser zoom at 200%
- Provide sufficient color contrast

**DON'T:**

- Use text smaller than 12px (except in rare cases)
- Set line-height below 1.25 for body text
- Use all-caps for long text (reduces readability)
- Justify text (creates uneven spacing)
- Use pure black (#000) on pure white (too harsh)

```css

  font-family: var(--dsai-typography-font-family-base);
  font-size: var(--dsai-typography-headings-h1-font-size);

.body-text {
  font-size: var(--dsai-typography-font-size-base);
  line-height: var(--dsai-typography-line-height-base);
```

## Bootstrap Compatibility

| DSAi Token                       | Bootstrap Variable    |
| -------------------------------- | --------------------- |

| `typography.fontSize.lg`         | `$font-size-lg`       |
| `typography.fontWeight.*`        | `$font-weight-*`      |
| `typography.lineHeight.base`     | `$line-height-base`   |

| `typography.lead.fontSize`       | `$lead-font-size`     |
| `typography.small.fontSize`      | `$small-font-size`    |
