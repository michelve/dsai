# Getting Started

This guide will help you get up and running with DSAi components in your React application.

## Installation

### Prerequisites

- Node.js 18+ or 20+
- React 18+
- TypeScript 5.0+ (recommended)

### Install Packages

```bash
# Using pnpm (recommended)
pnpm add @dsai/react @dsai/tokens

# Using npm
npm install @dsai/react @dsai/tokens

# Using yarn
yarn add @dsai/react @dsai/tokens
```

## Basic Setup

### 1. Import CSS Framework

DSAi is a **Bootstrap-first design system**. Import the CSS at the root of your application:

**Recommended: Bootstrap + DSAi Utilities**

```tsx
// In your main entry file (e.g., main.tsx or App.tsx)

// Bootstrap 5.3 theme customized with DSAi design tokens
import '@dsai/tokens/dist/css/dsai-theme-bs.css';

// DSAi utilities for accessibility and semantic patterns
import '@dsai/tokens/dist/css/dsai.css';
```

✅ **This gives you:**

- Full Bootstrap 5.3 component library with DSAi colors, typography, and spacing
- All DSAi design tokens as CSS custom properties
- WCAG 2.2 AA accessibility utilities (`.sr-only`, `.focus-ring`, `.skip-link`)
- Semantic patterns (`.container`, `.stack`, `.cluster`, `.status-success`)
- Consistent styling across all components

---

**Alternative Options:**

| CSS File            | Size  | Use Case                                               |
| ------------------- | ----- | ------------------------------------------------------ |
| `dsai-theme-bs.css` | 238KB | Full Bootstrap + DSAi tokens (required for components) |
| `dsai.css`          | 34KB  | DSAi utilities + accessibility (recommended addition)  |
| `variables.css`     | 16KB  | Just tokens, no utilities (minimal projects)           |

> ⚠️ **Important:** Always include `dsai-theme-bs.css` when using DSAi React components to ensure proper styling and avoid CSS conflicts

### 2. Use Components

```tsx
import { Button } from '@dsai/react';

function App() {
  return (
    <Button variant="primary" size="md">
      Click Me
    </Button>
  );
}
```

## Using Design Tokens

### CSS Variables

All design tokens are available as CSS custom properties:

```css
.my-component {
  color: var(--dsai-theme-primary);
  padding: var(--dsai-spacing-3);
  border-radius: var(--dsai-border-radius-md);
  box-shadow: var(--dsai-shadow-default);
}
```

### JavaScript/TypeScript

Import tokens directly in your code:

```typescript
import tokens from '@dsai/tokens';

const styles = {
  backgroundColor: tokens.theme.primary,
  padding: tokens.spacing['3'],
  borderRadius: tokens.border.radius.md,
};
```

### SCSS

For SCSS projects:

```scss
@import '@dsai/tokens/dist/scss/variables';

.my-component {
  background-color: $theme-primary;
  padding: $spacing-3;
  border-radius: $border-radius-md;
}
```

## TypeScript Configuration

DSAi is built with TypeScript and provides full type definitions. Ensure your `tsconfig.json` includes:

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "esModuleInterop": true,
    "skipLibCheck": true,
    "strict": true,
    "moduleResolution": "bundler"
  }
}
```

## Tree Shaking

DSAi supports tree shaking out of the box. Import only the components you need:

```tsx
// Good - Only Button is bundled
import { Button } from '@dsai/react';

// Avoid - Entire library bundled
import * as DSAi from '@dsai/react';
```

## Styling Approach

DSAi components use CSS-in-JS with design tokens. You can customize components in three ways:

### 1. Props API (Recommended)

```tsx
<Button variant="primary" size="lg" fullWidth>
  Full Width Button
</Button>
```

### 2. CSS Variables Override

```css
.custom-button {
  --dsai-theme-primary: #ff6b6b;
  --dsai-border-radius-md: 12px;
}
```

```tsx
<Button className="custom-button">Custom Styled</Button>
```

### 3. Style Prop

```tsx
<Button style={{ backgroundColor: 'purple', color: 'white' }}>Custom Button</Button>
```

## Accessibility

All DSAi components are WCAG 2.1 AA compliant. To maintain accessibility:

1. **Always provide labels**: Use `aria-label` when text content isn't visible
2. **Keyboard navigation**: All interactive elements support keyboard
3. **Focus management**: Components handle focus states automatically
4. **Screen readers**: ARIA attributes are included

```tsx
// Good
<Button aria-label="Close dialog">×</Button>

// Missing label
<Button>×</Button>
```

## Dark Mode Support

DSAi includes built-in dark mode support. Toggle themes by adding a class:

```tsx
// Add to root element
<div className="dark">
  {/* All components automatically adjust */}
  <Button variant="primary">Dark Mode Button</Button>
</div>
```

Or use CSS:

```css
/* Dark mode via media query */
@media (prefers-color-scheme: dark) {
  :root {
    /* Tokens automatically adjust */
  }
}
```
