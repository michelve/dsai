# Welcome to DSAi Component Library

**DSAi** is an enterprise-grade React component library built with accessibility, performance, and developer experience as core principles.

## 🎯 Vision

A modern, token-based design system that provides:

- **38 carefully crafted components** replacing Bootstrap 5
- **Full accessibility** (WCAG 2.1 AA compliance)
- **Figma integration** with bi-directional synchronization
- **TypeScript-first** with strict type safety
- **Comprehensive documentation** and examples

## 🚀 Quick Start

```bash
# Install the component library
pnpm add @dsai/react @dsai/tokens

# Import components
import { Button, Card } from '@dsai/react';
import '@dsai/tokens/dist/css/variables.css';
```

## 🎨 Design System Architecture

DSAi follows a token-based architecture:

```
Figma Variables → JSON Tokens → Style Dictionary → CSS/JS/TS/SCSS
                                                  ↓
                                           React Components
```

All components consume design tokens, ensuring consistency and easy theming.

## ✨ Key Features

- **Token-Based**: Every visual property defined by design tokens
- **Accessible**: WCAG 2.1 AA compliant out of the box
- **TypeScript**: Full type safety and IntelliSense
- **Tree-Shakeable**: Import only what you need
- **Dark Mode**: Built-in support for light/dark themes
- **Figma Integration**: Synchronized with Figma design files
- **Tested**: Comprehensive unit, integration, and accessibility tests
