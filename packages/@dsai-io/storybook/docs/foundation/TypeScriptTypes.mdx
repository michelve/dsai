# TypeScript Types Reference

DSAi design tokens are generated locally in each app using `@dsai/tools`. This provides full TypeScript support with type-safe access, IntelliSense, and compile-time validation.

## Setup

Generate tokens locally using the CLI:

```bash
pnpm add @dsai/tools
dsai tokens build
```

This generates `src/generated/tokens.js` and `src/generated/tokens.ts` in your project.

## Import Patterns

### Flat Token Imports (Recommended)

```typescript
import { colorBlue500, spacing4, themePrimary } from './generated/tokens';

const styles = {
  color: colorBlue500,
  padding: spacing4,
  backgroundColor: themePrimary,
};
```

### Grouped Token Access

Create a grouped tokens file (see `src/generated/tokens-grouped.ts`) for nested access:

```typescript
import tokens from './generated/tokens-grouped';

const blue = tokens.color.blue['500'].value;
const primary = tokens.theme.primary.value;
```

## CSS Variables

Use CSS custom properties directly:

```css
.my-component {
  color: var(--dsai-color-blue-500);
  padding: var(--dsai-spacing-4);
  background: var(--dsai-theme-primary);
}
```

---

## Available Token Categories

| Category | Description | Example Values |
|----------|-------------|----------------|
| `color*` | All color tokens | `colorBlue500` |
| `spacing*` | Spacing scale | `spacing4` |
| `typography*` | Typography tokens | `typographyFontWeightBold` |
| `theme*` | Theme colors | `themePrimary` |
| `border*` | Border tokens | `borderRadiusMd` |
| `background*` | Background colors | `backgroundWhite` |

---

## IntelliSense Support

All token imports provide full IntelliSense in VS Code and other TypeScript-aware editors:

- **Autocomplete**: Type `color` and see all color tokens
- **Hover Info**: See token values and descriptions
- **Go to Definition**: Jump to token source

---

## Token Generation

### Adding New Tokens

1. Add token to your DTCG JSON source files
2. Run `dsai tokens build` to regenerate outputs
3. Import new token in your code

### Updating Tokens

1. Update token value in JSON source
2. Run `dsai tokens build`
3. Generated files update automatically
